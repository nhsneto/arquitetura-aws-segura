# Arquitetura Cloud Segura (AWS)

## Contexto

Uma empresa está planejando migrar sua aplicação web para a **nuvem**. Atualmente, a aplicação permite que seus clientes acessem uma interface web, utilizem funcionalidades disponibilizadas por uma API, armazenem informações em um banco de dados e enviem arquivos para armazenamento.

A empresa precisa projetar uma arquitetura que permita o funcionamento da aplicação **sem expor** desnecessariamente seus componentes internos à internet.

## Objetivo

Elaborar uma proposta de **arquitetura cloud segura**, considerando o isolamento dos recursos, o controle de acesso, a proteção das comunicações e o monitoramento das atividades.
